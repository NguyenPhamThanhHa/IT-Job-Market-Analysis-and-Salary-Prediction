Employee Performance Evaluation System
Hệ thống hỗ trợ đánh giá hiệu suất công việc dựa trên các tiêu chí và chỉ số KPI được cấu hình linh hoạt.

Mục tiêu
Tự động hóa quy trình đánh giá nhân viên.
Quản lý tiêu chí đánh giá theo từng vị trí công việc.
Theo dõi kết quả và xếp loại hiệu suất.
Hỗ trợ báo cáo và thống kê trực quan.
Tính năng chính
Quản lý nhân viên.
Quản lý tiêu chí đánh giá.
Thiết lập trọng số cho từng tiêu chí.
Thực hiện đánh giá và tính điểm tự động.
Dashboard thống kê kết quả.
Công nghệ
Frontend: ReactJS / Angular
Backend: .NET / Java Spring Boot / Node.js
Database: SQL Server / MySQL
Authentication: JWT
